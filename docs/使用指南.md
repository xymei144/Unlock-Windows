# 蓝牙距离锁 · 开始使用

手机当「距离钥匙」：**人在电脑前自动解锁，人走开自动锁屏**。
不用装手机 App，不用联网，不采集任何数据。

---

## 先确认这四件事

| 项目 | 要求 |
|------|------|
| 系统 | Windows 10 / 11，**64 位** |
| 运行库 | 需要 **.NET Framework 4.8** —— Windows 11 和 2019 年 5 月之后的 Windows 10 都**已自带**，无需安装；更老的系统会弹窗提示，装一次即可（见下） |
| 蓝牙 | 蓝牙 **4.0 以上**（2014 年之后的笔记本基本都有；台式机若只有老式蓝牙适配器可能不支持低功耗广播） |
| 手机 | iPhone 或任何会持续广播的蓝牙低功耗设备（安卓手机同样可以） |

网络：**完全不需要**。整个判断过程只用到电脑本机的蓝牙信号强度。

**其它都不用装**：不需要 VC++ 运行库、不需要 WebView2、不需要任何微软商店组件 —— 本程序把需要的东西都带齐了，解压即用。

> **万一提示缺 .NET Framework？** 双击 `UnlockServer.exe` 时如果 Windows 弹出「此应用需要 .NET Framework」的蓝色提示框，直接点里面的「下载」按钮装一下就好（在线安装器约 1.5 MB）。装完再双击一次。

---

## 三步搞定

### 第 1 步 · 启用本机解锁（只有这一步需要管理员权限）

1. 双击 `UnlockServer.exe`，会弹 UAC 授权框，点「是」
2. 切到「**解锁**」页 → 填入**你自己的 Windows 登录用户名和密码** → 点「**启用本机解锁**」
3. 提示成功后，**重启一次电脑**（让登录界面重新加载组件）

> **它做了什么**：把一个很小的时间差组件（`UnlockServer.Provider.dll`）装到
> `C:\Program Files\UnlockServer\`，并注册到 Windows 的登录界面。
> 你的密码经 Windows 自带的 DPAPI 加密后**只存在本机**，不联网、不上传。
>
> **不想托管密码？** 第 1 步可以跳过，只开「离开自动锁屏」——不过那就没有靠近自动解锁了。
> 如果你只想要「离开自动锁」，Windows 10/11 自带的**动态锁**
> （设置 → 蓝牙和设备 → 手机连接 → 动态锁）零安装、零风险，但同样只能锁、不能自动解。

### 第 2 步 · 把你自己的手机加进去（本包没预置任何设备）

1. 「**设备**」页 → 点「**添加设备**」
2. 在弹出的扫描窗口里，筛选切到「**低功耗**」
3. 找到属于你手机的那一条（**怎么认，见下一节**）→ 选中 → 确定
4. 回到主界面，卡片上点「**改名**」，改成「我的手机」之类你自己认得的名字

加好之后，「设备」页应该显示 `监控: 1/1 在范围内`。

### 第 3 步 · 打开规则

「**规则**」页 → 打开「自动锁定」和「自动解锁」→ 保存。完成。

## 怎么认出哪条是你的手机（最容易卡住的一步）

苹果（和多数安卓）手机的蓝牙低功耗地址是**随时轮换的随机地址**，广播名也是一串乱码，
所以列表里看着都像天书。用这个办法一定能认出来：

> **把扫描窗口开着，然后在你手机上关掉蓝牙，等 10 秒再打开。**
> 列表里**消失又出现**的那一条，就是你的手机。

辅助判断：

- **地址第一段在 `40` ~ `7F` 之间的，基本是苹果设备**（随机私有地址的特征）；
- 名字是乱码（类似 `NGNW+g+PwCZ8Fikv...`）——这是苹果故意混淆的，**正常现象**，
  同一台手机这个名字是稳定的，所以认出来之后就不用再管了；
- 名字里带品牌、带 `-Find My`、带耳机型号的，是别的设备（耳机、防丢标签等），不用加。

> **别加错类型**：手机在电脑的蓝牙记录里可能同时有「经典地址」和「低功耗地址」两个身份。
> 只有**低功耗（BLE）**那个才能当钥匙——经典地址不广播，加进去永远是「未连接」。
> 本包在扫描窗口已经按真实类型标注（`低功耗` / `Classic`），筛选「低功耗」再选就不会错。

> **Apple Watch 不行**：手表只在够不到手机时才自己广播，而你需要它的场合（人在电脑前、手表戴手上）
> 它恰好不广播。请用手机。

## 常见问题

**双击后没反应 / 被杀毒软件拦下来？**
主程序没有购买数字签名证书，Windows SmartScreen 和部分杀软会提示"未知发布者"。
点「更多信息 → 仍要运行」即可。若被拦截，把整个文件夹加入杀软的信任区。

**「设备」页一直显示 `0/1`？**
参数顺序排查：① 手机蓝牙是否开着；② 手机是否就在电脑旁边（1~3 米内）；
③ 「设备」页里的那条是不是**低功耗**类型（卡片上会标）。
都正常的话，把手机蓝牙关一下再打开，看信号强度（dBm）有没有跳动。

**重启之后要重新设置吗？**
不用。配置存在文件夹里的 `unlockserver.ini` 和 `devices.json`，
换电脑的话把整个文件夹拷过去，只要重做第 1 步（装组件）。

**怎么调灵敏度？**
「规则」页可以改：信号阈值（默认 `-70` dBm，越接近 0 表示要求越近）、
离开延迟、进入延迟。实测坐在电脑前大约 `-20 ~ -34`，默认值留了很大余量。

**怎么卸载？**
「解锁」页 → 「卸载本机解锁」→ 重启。然后把整个文件夹删掉即可，
注册表里的启动项在「规则」页关掉「开机自启」时自动清理。

## 目录说明

| 文件 | 说明 |
|------|------|
| `UnlockServer.exe` | 主程序，双击即用 |
| `UnlockServer.Provider.dll` | 登录界面组件（第 1 步会装到 Program Files） |
| `devices.json` | 你的设备列表，添加设备后自动生成 |
| `device-aliases.tsv` | 软件自动学习的「广播名 → 设备」对照表，自动维护，不用管 |
| `unlockserver.ini` | 规则与阈值，**首次运行后自动生成** |
| 几个 `.dll` / `.winmd` | 运行依赖，别删 |
| `可选-高级工具\` | 诊断工具，平时用不到 |
| `Logs\` | 运行日志，**首次运行后自动生成** |
